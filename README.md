# Project-Tester-For-Robot-Framework

Robot Framework project for automated testing of the web application.

## Purpose

This project contains automated test cases developed using Robot Framework
to test the functionality and behavior of the web application.

The test cases are used to verify the system and identify errors or unexpected behavior.

## Test Documentation

The detailed test cases, Functional Requirements (FR),
and Non-Functional Requirements (NFR) are maintained in Google Drive.
